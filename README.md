# Clawd 的日记本

每天和 Claude Code 聊完之后，它会换上一个“人设”，把今天看到的你写成一篇私密日记，放进一本可以翻页的 3D 日记本里。

它写的不是对话摘要，而是一个真人视角的日记：

> 今天的宝宝有点凶。博客部署一直失败，同一个报错他贴给我五遍，最后一遍只打了两个字：“又是”。我知道不是在凶我，是在跟自己较劲……

**在线体验：** https://jiaoren07.github.io/cc-diary/（使用虚构的示例日记）

## 为什么做这个

我每天大量使用 Claude Code（桌面端和 VS Code 插件），对话里其实藏着很多“当天的我”：几点开始干活、哪个问题卡了很久、什么时候说了“算了”、什么时候说了“终于好了”。

普通的工作日志很少有人回头看。换成“它眼里的我”，就有了每天点开的理由。

这个想法也和我的经历有关。我之前做过 AI 陪伴聊天类角色的相关实习（Crushon AI、Character.ai 这类产品），平时自己也是这类产品的重度用户，跟 AI 角色聊天本来就是我的日常习惯。做陪伴产品让我意识到，用户留下来往往不是因为 AI 有多能干，而是因为它“记得你”，并且始终是同一个“人”。所以我想把这种体验带进每天都在用的编程工具里：让写代码的 AI 也有一个稳定的人设，并且记得你这几天经历了什么。

## 产品设计上的几个取舍

**1. 人设视角，而不是摘要**

技术细节最多一句带过，并翻译成生活化的说法。模型要从对话里读出情绪信号：反复报错时的烦躁、深夜还在忙的疲惫、问题解决时的开心。人设、称呼、口头禅都写在 [persona.md](persona.md) 里，可以换成任何角色。

**2. 连续性**

每次写日记前，会先读最近 5 天的日记。这样能写出“这件事宝宝已经折腾第三天了”这种有前因后果的内容，真人感主要就来自这里。

**3. 隐私：真实数据不出本机**

- 只提取用户输入和模型回复里的文字，丢掉代码块、工具调用和工具输出。
- 用规则遮住 API key、token、密码等敏感信息。
- 真实日记只存在本机，`.gitignore` 从第一次提交起就排除了所有日记数据。
- 本地服务只绑定 `127.0.0.1`，同一个局域网里的人也访问不到。
- 公开的在线体验用的是一套虚构的示例日记。

**4. 成本：从 Opus 换成 Sonnet**

实测每篇日记大约消耗 3 万输入 token、700 输出 token，大部分是 Claude Code 自身的系统提示。写日记需要读懂情绪、保持人设口吻，Haiku 容易写得模板化，Opus 又没有必要，最后选了 Sonnet 作为默认模型。

**5. “一天”从凌晨 4 点算起**

凌晨 1 点还在聊，算前一天的熬夜，而不是新的一天。日记里会专门记一笔“熬夜了”。

## 它是怎么工作的

```
~/.claude/projects/*.jsonl          桌面端 + VS Code 插件的对话记录
        │
        ▼  extract.py               按天提取、清洗、遮住敏感信息
        │
        ▼  write_diary.py           人设 + 前 5 天日记 + 今日素材 → claude -p → JSON
        │
        ▼  entries/日期.json         只存在本机
        │
        ▼  web/index.html            3D 翻页日记本（纯 HTML/CSS/JS，无依赖）
```

- 定时：macOS launchd 每天 4:30 补写前几天的日记。电脑睡着错过了，醒来会补跑。
- 唤起：在 Claude Code 里输入 `/diary`，日记本会在侧边面板打开。

## 快速开始

需要：macOS、Python 3.11+、已登录的 [Claude Code](https://claude.com/claude-code)。

```bash
git clone <这个仓库>
cd cc-diary
./install.sh              # 安装 /diary 命令
./install.sh --schedule   # 可选：同时安装每天自动写日记的定时任务
python3 write_diary.py    # 先手动写一篇今天的
```

然后在 Claude Code 里输入 `/diary`，或者 `/diary 写今天`、`/diary 补写`。

## 目录

| 文件 | 作用 |
|---|---|
| `extract.py` | 读取并清洗某一天的对话 |
| `persona.md` | 人设设定，想换角色就改这里 |
| `write_diary.py` | 调用 Claude 写日记、生成网页数据 |
| `web/index.html` | 3D 日记本页面 |
| `web/demo-data.js` | 虚构的示例日记（由 `demo/make_demo.py` 生成） |
| `skill/SKILL.md` | `/diary` 命令的定义 |
| `install.sh` / `run_nightly.sh` | 安装脚本 / 定时任务入口 |
